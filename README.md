### 🚀 Featured Projects

#### 🌐 1. [Social Network Microservices (Golang)](https://github.com/thangtranitwork/social-network-micro-services-go)
A full-stack, event-driven social network system powered by **13 Golang Microservices**, gRPC inter-service communication, polyglot persistence, and real-time WebRTC/WebSocket calling.

- ⚡ **13 Microservices Architecture:** API Gateway, Auth, User, Post, Chat, Notification, FCM, File, Admin, Search, Story, AI & Recommendation Service.
- ⚡ **Communication & Streaming:** `gRPC` + `Protobuf` for low-latency RPC, `Apache Kafka` for event-driven messaging, `WebSocket & WebRTC` for real-time chat & video calling.
- ⚡ **Polyglot Persistence:** `PostgreSQL`, `Neo4j` (Graph DB for social connections), `Redis` (caching & session), `MongoDB` (chat history), and `MinIO` (object storage).
- ⚡ **DevOps & Observability:** Smart GitHub Actions CI/CD (diff-based service compilation & deployment), Docker Compose, Nginx, Log Streamer & System Health Dashboards.

#### 🛠️ 2. [Deployment & Monitoring Services System](https://github.com/thangtranitwork/deployment-and-monitoring-services-system)
An enterprise-grade DevOps platform & developer control center built with **Golang Backend & React SPA**, featuring parallel multi-service deployments, real-time server telemetry, Git workspace management, and developer utility suites.

- ⚡ **Parallel Multi-Deploy Matrix:** Concurrent multi-service compilation and deployment with real-time log streaming and retry matrix.
- ⚡ **Real-Time Server Monitoring:** Live CPU, Memory, Uptime, and Port bindings telemetry via Server-Sent Events (SSE).
- ⚡ **Git Workspace & Staging Control:** Branch compare, staging auto-sync, line-by-line diff inspector, and VS-Code-like commit panel.
- ⚡ **Developer Utility Suite (IDS Tools):** 13 integrated tools including JWT Decoder/Signer, 100% Read-Only SQL Mutation Preview Engine, cURL Runner, and Bcrypt Validator.
